# FOODWISE AI 

> AI 기반 외식업 음식물쓰레기·식자재 비용 예측·관리 시스템  
> **버린 후 관리에서, 버리기 전 예방으로**

FOODWISE AI는 외식업체의 판매량, 예약, 날씨, 재고 등의 데이터를 활용하여  
다음 날의 수요를 예측하고 적정 발주량과 조리량을 제안하는 웹 기반 프로토타입입니다.

음식물쓰레기가 발생한 이후 처리하는 것보다  
**필요한 만큼 구매하고, 필요한 만큼 조리하여 음식물쓰레기 발생 자체를 줄이는 것**을 목표로 합니다.

---

## 1. 프로젝트 배경

외식업에서는 요일, 날씨, 예약 인원, 메뉴 등에 따라 매일 고객 수요가 달라집니다.

수요를 정확하게 예상하지 못하면 필요 이상의 식재료를 구매하거나 음식을 조리하게 되고,  
이는 식자재 비용 손실과 음식물쓰레기 증가로 이어질 수 있습니다.

FOODWISE AI는 다음 질문에서 시작했습니다.

> **"내일 얼마나 준비해야 음식물쓰레기와 비용을 동시에 줄일 수 있을까?"**

---

## 2. 주요 기능

### 📊 Dashboard
예상 방문객, 예상 식자재 비용, 예상 폐기량 등 주요 정보를 한눈에 확인할 수 있습니다.

### 📈 AI 수요 예측
예약 인원, 요일, 날씨, 기온, 이벤트 등의 정보를 바탕으로  
예상 방문객 수와 메뉴별 예상 수요를 제공합니다.

### 📦 발주 최적화
예상 판매량과 메뉴별 식재료 필요량, 현재 재고를 비교하여  
추가로 필요한 식재료와 추천 발주량을 계산합니다.

### ⚖️ 음식물쓰레기 분석
실제 서비스에서는 음식물 수거통 하단의 Load Cell 무게 센서를 통해  
시간대별 음식물쓰레기 무게를 자동으로 측정하고 기록하는 구조를 제안합니다.

현재 프로토타입에서는 실제 센서를 연결하지 않고  
센서 측정 데이터를 시뮬레이션하여 기능을 구현했습니다.

### 💰 비용 분석
기존 구매 방식과 FOODWISE의 추천 발주 방식을 비교하여  
예상 식자재 비용과 절감 가능 금액을 확인할 수 있습니다.

### 📋 Weekly Report
주간 음식물쓰레기 발생량과 식자재 비용 변화를 확인하고  
운영 데이터를 쉽게 비교할 수 있도록 구성했습니다.

## 3. 서비스 동작 과정

```text
판매 · 예약 · 날씨 · 재고 데이터
              ↓
          수요 예측
              ↓
       메뉴별 예상 판매량
              ↓
       식재료 필요량 계산
              ↓
        현재 재고 반영
              ↓
      적정 발주량 · 비용 제안
              ↓
     음식물쓰레기 무게 측정
              ↓
          데이터 축적
              ↓
       향후 예측에 활용
```text
4. 구현 방식

이번 프로젝트는 실제 외식업체의 충분한 학습 데이터를 확보하기 어려운 점을 고려하여
실제 AI 모델을 학습시키는 대신 예측 및 센서 데이터를 시뮬레이션하는 방식으로 구현한 프로토타입입니다.

현재 수요 예측은 예약 인원과 요일, 날씨, 기온, 이벤트 등의 조건을 반영하는
프로토타입 예측 로직을 사용합니다.

발주량은 예상 수요를 바탕으로 필요한 식재료의 양을 계산한 뒤
현재 재고량을 제외하여 산출합니다.

수요는 예측하고, 발주량은 계산하는 구조입니다.

향후 실제 POS 판매 데이터, 예약 데이터, 날씨, 재고 및 음식물쓰레기 측정 데이터가 축적되면
현재의 시뮬레이션 로직을 실제 학습 기반 예측 모델로 확장할 수 있습니다.

5. 음식물쓰레기 측정 방식

기존의 수기 기록 방식 대신 음식물 수거통 하단에
Load Cell 무게 센서를 설치하는 방식을 제안했습니다.

음식물 수거
    ↓
무게 센서 측정
    ↓
데이터 자동 기록
    ↓
시간대별 폐기량 저장
    ↓
향후 수요 및 폐기량 예측 데이터로 활용

현재 웹 프로토타입에 표시되는 센서 측정값은
실제 하드웨어에서 수집한 데이터가 아닌 시뮬레이션 데이터입니다.

호텔, 학교 급식, 프랜차이즈 등으로 적용 범위 확대
